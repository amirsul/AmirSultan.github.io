Nearest Library Finder Website for PG County Students

Built a web app using HTML, CSS, JavaScript, and Leaflet.js, leveraging the PG County Open Data API to help students find the nearest public libraries from their school or home. Inspired by limited school library access and inequities in Prince George’s County (history of redlining, underfunding, many first-gen students), the tool connects students with community resources to support academic success. Features include an interactive map showing local libraries, a search bar to calculate distances from addresses or ZIP codes, and a live demo highlighting ease of use.

No Anxiety Prep Website

Redesigned the No Anxiety Test Prep (NAP) website with a team using Figma and UX research methods to create an intuitive, stress-reducing platform for students, parents, and tutors seeking test prep, college admissions, and international study support. Tasked with improving user experience and NAP’s online presence, we conducted user interviews, streamlined navigation, organized detailed service paths for pre-college, grad, and international students, and added features like community testimonials, tutor profiles, a comprehensive FAQ, and an accessible contact form. Employed calming green tones and clear interactive elements to reinforce the goal of reducing anxiety and making educational resources easy to access.
